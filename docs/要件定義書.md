# 習慣化×タスク管理アプリ 要件定義書

## 1. アプリ概要

### 1.1 目的
タスク管理と習慣化を組み合わせ、前日夜にタスクを設定し、翌朝に優先順位付きスケジュールが自動生成されるアプリケーション

### 1.2 基本フロー
1. 前日の夜：翌日のタスクを登録
2. 優先順位付け：重要度（手動）×緊急度（期日から自動計算）
3. 翌朝：自動生成されたスケジュールを表示
4. 実行・完了：スワイプ操作でタスク完了

## 2. 技術仕様

### 2.1 技術スタック
- **フロントエンド**: Next.js (App Router) + TypeScript + Tailwind CSS
- **状態管理**: Zustand
- **フォーム管理**: React Hook Form
- **グラフ**: Recharts
- **バックエンド・DB**: Supabase (PostgreSQL)
- **認証**: Supabase Auth (メール + Google OAuth)
- **通知**: Web Push API + Service Worker
- **対応**: レスポンシブデザイン（PC・タブレット・スマートフォン対応）

### 2.2 データベース設計
```sql
-- ユーザー (Supabase Auth使用)

-- 長期目標
long_term_goals (id, user_id, title, period, deadline, created_at)

-- 短期目標
short_term_goals (id, user_id, long_term_goal_id, title, target_count, created_at)

-- カテゴリ
categories (id, user_id, name, color)

-- 習慣項目

```

## 3. 機能要件

### 3.1 認証機能
- メール認証による新規登録・ログイン
- Google OAuth連携
- Supabaseによる安全なユーザー管理

### 3.2 目標設定機能

#### 3.2.1 階層構造
**3層階層構造:**
```
長期目標（例: TOEIC 800点達成）
  └─ 短期目標（例: 単語を1000個覚える）
      └─ 習慣（例: 単語学習30分）
```

**階層関係:**
- 習慣 → 短期目標（1対1、必須紐づけ）
- 短期目標 → 長期目標（1対1、必須紐づけ）
- 1つの習慣は1つの短期目標にのみ紐づく
- 1つの短期目標は1つの長期目標にのみ紐づく

#### 3.2.2 長期目標の仕様
**作成項目:**
- タイトル（必須）
- 期限（必須）: 3ヶ月・6ヶ月・1年から選択
- 説明文（任意）

**制約:**
- 期限の開始日は「今日」から起算
- 複数の長期目標を同時に設定可能（上限なし）

**進捗計算:**
- 紐づく短期目標の達成率の平均で計算
- 計算式: `長期目標の進捗率 = Σ(短期目標の進捗率) / 短期目標の総数`

**達成条件:**
- 全ての短期目標が達成済み（100%）になったら達成

#### 3.2.3 短期目標の仕様
**作成項目:**
- タイトル（必須）
- 長期目標の選択（必須）
- 目標値（必須）: ユーザーが自由に設定（小数点可）
- 測定単位（必須）: プリセット or カスタム単位
- 期限（任意）
- 達成後の表示設定（任意）: 継続表示 or 非表示

**目標値の種類（定量的なもの）:**
- 回数ベース: 「習慣を30回実行」
- 日数ベース: 「習慣を30日継続」
- 時間ベース: 「習慣で合計1000分実行」
- 単語ベース: 「単語を100語覚える」
- 金額ベース: 「10万円貯める」
- 冊数ベース: 「本を10冊読む」
- カスタム: ユーザー定義の単位

**進捗計算:**
- 全ての単位で共通: `進捗率 = (現在値 / 目標値) × 100`
- 100%超過も表示（例: 120%）
- 進捗は累積方式

**達成条件:**
- 進捗率が100%以上になったら自動的に達成
- 達成後も実行は継続可能（進捗率は100%超も表示）
- 達成後の表示/非表示はユーザーが選択可能

#### 3.2.3.1 測定単位の詳細仕様

**プリセット単位:**
| 単位 | 入力方法 | 説明 |
|------|----------|------|
| 回数 | 自動+1 | タスク完了で自動的に+1 |
| 日数 | 自動+1 | 1日1回のみカウント（同日複数完了でも+1） |
| 時間（分） | 自動計算 | 実行時間から自動計算、モーダル内で編集可 |
| 単語 | 手動入力 | タスク完了時に数値を入力 |
| 円 | 手動入力 | タスク完了時に数値を入力 |
| 冊 | 手動入力 | タスク完了時に数値を入力 |

**カスタム単位:**
- ユーザーが自由に追加可能（例: ページ、km、kg など）
- カスタム単位は全て手動入力
- ユーザーごとに保存（自分だけが使用可能）
- 使用中の目標がなければ削除可能
- 追加場所: 短期目標作成時のドロップダウンに「+ 新規追加」

**時間の表示形式:**
- 90分 → 「1時間30分」のように変換して表示
- 保存は分単位で行う

#### 3.2.3.2 タスク完了時の進捗入力

**自動入力の場合（回数・日数）:**
```
┌─────────────────────────────────┐
│  ✓ タスク完了                    │
├─────────────────────────────────┤
│  朝のランニング                   │
│  進捗: +1日 (15 → 16/30日)       │
│                                 │
│  [完了]                         │
└─────────────────────────────────┘
```

**自動入力（時間）+ 編集可能:**
```
┌─────────────────────────────────┐
│  ✓ タスク完了                    │
├─────────────────────────────────┤
│  朝の読書                        │
│                                 │
│  実行時間: [ 25 ] 分  ← 編集可能  │
│  進捗: 45 → 70/120分 (58%)       │
│                                 │
│  [完了]                         │
└─────────────────────────────────┘
```

**手動入力（単語・円・冊・カスタム）:**
```
┌─────────────────────────────────┐
│  ✓ タスク完了                    │
├─────────────────────────────────┤
│  単語学習                        │
│                                 │
│  今回の成果: [    ] 単語          │
│  進捗: 50 → ?/100語              │
│                                 │
│  [進捗なしで完了]  [完了]          │
└─────────────────────────────────┘
```

**進捗の修正:**
- 「修正」ボタンで履歴から過去の入力を修正可能
- 修正履歴は記録される

#### 3.2.4 習慣と目標の紐づけ
**紐づけの必須性:**
- 全ての習慣は短期目標に紐づけ必須
- 目標なしの習慣は作成不可

**紐づけのタイミング:**
- 習慣作成時に短期目標を必ず選択
- 既存の習慣の紐づけ変更も可能

**紐づけの編集:**
- 習慣編集画面で紐づけ先の短期目標を変更可能
- 変更時は過去の実行履歴もそのまま保持

#### 3.2.5 目標削除時の挙動
**長期目標の削除:**
1. 確認ダイアログを表示
2. 削除を実行すると:
   - 長期目標自体は削除
   - 紐づく短期目標は削除
   - 習慣は削除されない（目標紐づけのみ解除）
3. 削除前に警告メッセージを表示

**短期目標の削除:**
1. 確認ダイアログを表示
2. 削除を実行すると:
   - 短期目標自体は削除
   - 習慣は削除されない（目標紐づけのみ解除）
3. 削除前に警告メッセージを表示

**習慣の紐づけ解除後:**
- 目標紐づけが解除された習慣は「未紐づけ」状態になる
- 習慣一覧画面で「未紐づけ」習慣を確認・再紐づけ可能
- 実行履歴は全て保持される

**⚠️ 注意:**
- 目標の削除は取り消せない
- 習慣と実行履歴は保持されるため、新しい目標への再紐づけが可能

#### 3.2.6 進捗表示
**長期目標の進捗:**
- 進捗バー（0-100%）
- 達成済み短期目標数 / 総短期目標数
- 残り日数
- 達成予想日（現在のペースで継続した場合）

**短期目標の進捗:**
- 進捗バー（0-100%以上）
- 現在値 / 目標値（例: 20回 / 30回）
- 達成率（例: 66.7%）
- 紐づく習慣の実行状況

**色分けシステム:**
- 🔴 0-30%: 赤（要注意）
- 🟡 31-70%: 黄（頑張ろう）
- 🟢 71-99%: 緑（良好）
- 🔵 100%以上: 青（達成！）

### 3.3 習慣項目・カテゴリ管理
- ユーザーが自由に習慣項目を作成・編集・削除
- カテゴリは任意設定（健康、学習、家事など自由入力）
- 各習慣項目にデフォルト所要時間を設定（5分刻み）

### 3.4 優先度システム（アイゼンハワーマトリクス）
**重要度（手動設定・3段階）:**
- 高（3）・中（2）・低（1）

**緊急度（期日から自動計算）:**
- 緊急度3：当日中
- 緊急度2：3日前から当日前まで
- 緊急度1：4日以上前
- 期限なしタスク：必ず期日設定必須

**最終優先度 = 重要度 × 緊急度（1-9）**

**タスク配置ルール:**
1. 習慣タスクを別枠で優先配置
2. 単発タスクが緊急度3の場合のみ習慣タスクより優先
3. 同じ優先度内では登録順で配置

**表示方法:**
- 「優先度 9 (重要度3×緊急度3)」形式で表示

### 3.5 タスク管理機能
- タスク登録・編集・削除
- 繰り返しタスク（毎日/週複数回）と単発タスクの区別表示
- 緊急タスクの当日追加
- ドラッグ&ドロップでの並び替え
- 期日変更時の手動再計算機能
- 優先度のリアルタイム更新

### 3.6 スケジュール機能
**作業時間上限:**
- 曜日別に作業可能時間上限を設定
- 上限超過時の対応：
  - 期日に余裕がある場合：優先順位を下げて繰り越し
  - 期日に間に合わない場合：警告表示

**スケジュール調整:**
- 休憩時間の自動挿入
- タスク間のバッファ時間設定
- 遅延時の動的スケジュール再調整

**時間不足時の提案:**
- 早起き提案
- 昼休み活用提案
- 翌日分散提案
- 複数の解決策を提示

### 3.7 スケジュール表示
- **時間割ビュー**: タイムライン形式での表示
- **リストビュー**: 優先順位順のリスト表示
- ビューの切り替え可能
- レスポンシブ対応（PC・タブレット・スマートフォン）

### 3.8 タスク実行・完了
- スワイプ操作でタスク完了
- 実行時間の記録
- 完了状況のトラッキング

### 3.9 学習機能
- 習慣項目ごとに実行時間データを蓄積
- 次回タスク設定時に過去の平均時間を提案
- ユーザーが承認ボタンで確定する仕組み
- 見積もり精度向上のため継続学習

### 3.10 進捗表示システム
**蓄積型プログレスバー:**
- 完了回数ベースの進捗表示
- 上限100%ではなく、習慣が貯金箱に溜まっていく形式
- 目標達成後も継続して蓄積可能

**色分けシステム:**
- 🔴 0-30%：赤（要注意）
- 🟡 31-70%：黄（頑張ろう）
- 🟢 71-100%：緑（良好）
- 🔵 101%以上：青（目標達成）
- 🏆 大幅超過：金（素晴らしい！）

**週別視覚グラフ:**
- 直近4週間の進捗を視覚的に表示
- 週ごとの達成状況をドット表示
- 月間達成率と前月比較

### 3.11 通知機能
- タスク開始5分前のアラート通知
- Web Push API使用
- ブラウザ通知許可が必要

### 3.12 統計・レポート機能
- 日別・週別・月別の達成率
- 継続ストリーク表示
- 習慣の継続日数
- 最適な時間帯の提案
- 週間・月間振り返り機能

### 3.13 ユーザビリティ機能
- **ダークモード対応**

- **レスポンシブデザイン**（モバイルファースト）
