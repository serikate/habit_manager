# 習慣化×タスク管理アプリ 統合要件定義書

## 1. アプリ概要

### 1.1 目的
タスク管理と習慣化を組み合わせ、前日夜にタスクを設定し、翌朝に優先順位付きスケジュールが自動生成されるアプリケーション。さらに、**習慣の成長を見える化**することでモチベーションを高め、長期目標達成につなげる。

### 1.2 基本フロー
1. 前日の夜：翌日のタスクを登録
2. 優先順位付け：重要度（手動）×緊急度（期日から自動計算）
3. 翌朝：自動生成されたスケジュールを表示
4. 実行・完了：スワイプ操作でタスク完了
5. 成長可視化：習慣ごとのレベル・全体称号で進捗を実感

## 2. 技術仕様

### 2.1 技術スタック
- **フロントエンド**: Next.js (App Router) + TypeScript + Tailwind CSS
- **状態管理**: Zustand
- **フォーム管理**: React Hook Form
- **グラフ**: Recharts
- **バックエンド・DB**: Supabase (PostgreSQL)
- **認証**: Supabase Auth (メール + Google OAuth)
- **通知**: Web Push API + Service Worker
- **対応**: レスポンシブデザイン（PC・タブレット・スマートフォン対応）

### 2.2 データベース設計
```sql
-- ユーザー (Supabase Auth使用)

-- 長期目標
long_term_goals (id, user_id, title, period, deadline, created_at)

-- 短期目標
short_term_goals (id, user_id, long_term_goal_id, title, target_count, created_at)

-- カテゴリ
categories (id, user_id, name, color)

-- 習慣項目
habits (id, user_id, name, category_id, default_duration, avg_actual_duration, level, experience_points, is_active)

-- 習慣-目標関連
habit_goal_relations (id, habit_id, short_term_goal_id)

-- 日次タスク
daily_tasks (id, user_id, habit_id, date, estimated_duration, importance, deadline, is_recurring, status)

-- 実行履歴
task_executions (id, task_id, actual_duration, completed_at, achievement_rate)

-- 作業時間上限設定
work_limits (id, user_id, day_of_week, max_minutes)

-- ユーザー設定
user_settings (id, user_id, title_mode, notification_enabled, theme_mode)

-- 習慣レビュー
habit_reviews (id, user_id, habit_id, review_date, action, notes, created_at)
```

## 3. 機能要件

### 3.1 認証機能
- メール認証による新規登録・ログイン
- Google OAuth連携
- Supabaseによる安全なユーザー管理

### 3.2 目標設定機能
**3層階層構造:**
1. **長期目標**: 期限選択式（3ヶ月・6ヶ月・1年）
2. **短期目標**: 長期目標達成のための中間目標
3. **日次タスク**: 短期目標達成のための習慣的タスク

**仕様:**
- 自動生成なし（全て手動設定）
- 習慣項目は基本的に目標と紐づけて設定
- 1つの習慣項目は複数の目標に紐づけ可能
- 目標削除時は関連習慣項目も自動削除

### 3.3 習慣項目・カテゴリ管理
- ユーザーが自由に習慣項目を作成・編集・削除
- カテゴリは任意設定（健康、学習、家事など自由入力）
- 各習慣項目にデフォルト所要時間を設定（5分刻み）
- 習慣の休止・復活機能（レビュー時に休止リストへ移動）

### 3.4 優先度システム（アイゼンハワーマトリクス）
**重要度（手動設定・3段階）:**
- 高（3）・中（2）・低（1）

**緊急度（期日から自動計算）:**
- 緊急度3：当日中
- 緊急度2：3日前から当日前まで
- 緊急度1：4日以上前
- 期限なしタスク：必ず期日設定必須

**最終優先度 = 重要度 × 緊急度（1-9）**

**タスク配置ルール:**
1. 習慣タスクを別枠で優先配置
2. 単発タスクが緊急度3の場合のみ習慣タスクより優先
3. 同じ優先度内では登録順で配置

**表示方法:**
- 「優先度 9 (重要度3×緊急度3)」形式で表示

### 3.5 タスク管理機能
- タスク登録・編集・削除
- 繰り返しタスク（毎日/週複数回）と単発タスクの区別表示
- 緊急タスクの当日追加
- ドラッグ&ドロップでの並び替え
- 期日変更時の手動再計算機能
- 優先度のリアルタイム更新

### 3.6 スケジュール機能
**作業時間上限:**
- 曜日別に作業可能時間上限を設定
- 上限超過時の対応：
  - 期日に余裕がある場合：優先順位を下げて繰り越し
  - 期日に間に合わない場合：警告表示

**スケジュール調整:**
- 休憩時間の自動挿入
- タスク間のバッファ時間設定
- 遅延時の動的スケジュール再調整

**時間不足時の提案:**
- 早起き提案
- 昼休み活用提案
- 翌日分散提案
- 複数の解決策を提示

### 3.7 スケジュール表示
- **時間割ビュー**: タイムライン形式での表示
- **リストビュー**: 優先順位順のリスト表示
- ビューの切り替え可能
- レスポンシブ対応（PC・タブレット・スマートフォン）

### 3.8 タスク実行・完了
- スワイプ操作でタスク完了
- 実行時間の記録
- 完了状況のトラッキング
- 達成率の計算（実際の実行時間/予定時間）

### 3.9 学習機能
- 習慣項目ごとに実行時間データを蓄積
- 次回タスク設定時に過去の平均時間を提案
- ユーザーが承認ボタンで確定する仕組み
- 見積もり精度向上のため継続学習

### 3.10 進捗表示システム
**蓄積型プログレスバー:**
- 達成率ベースで進捗を表示（例：1日の達成率80%なら80ptを加算）
- 上限100%ではなく、習慣が貯金箱に溜まっていく形式
- 目標達成後も継続して蓄積可能

**色分けシステム:**
- 🔴 0-30%：赤（要注意）
- 🟡 31-70%：黄（頑張ろう）
- 🟢 71-100%：緑（良好）
- 🔵 101%以上：青（目標達成）
- 🏆 大幅超過：金（素晴らしい！）

**週別視覚グラフ:**
- 直近4週間の進捗を視覚的に表示
- 週ごとの達成状況をドット表示
- 月間達成率と前月比較

**週間・月間進捗:**
- 週ごと・月ごとの平均達成率を表示
- （拡張予定）カレンダービューで「できた日」だけ光らせる方式。未達成は空欄で表示しない

### 3.11 通知機能
- タスク開始5分前のアラート通知
- Web Push API使用
- ブラウザ通知許可が必要

### 3.12 統計・レポート機能
- 日別・週別・月別の達成率
- 継続ストリーク表示
- 習慣の継続日数
- 最適な時間帯の提案
- 週間・月間振り返り機能

### 3.13 ユーザビリティ機能
- **ダークモード対応**
- **キーボードショートカット**
- **データエクスポート機能**
- **レスポンシブデザイン**（モバイルファースト）

### 3.14 レベル＆称号システム（新機能）

**習慣ごとレベル:**
- 各習慣ごとに「達成率」を経験値として加算
- レベル上限は100を想定（長期的に育成可能）
- レベルアップ時に軽い演出（バー点灯・数字ポップアップ）

**全体レベル（習慣力）:**
- 全習慣の平均レベルを算出し、ダッシュボード上部に「全体レベル」として表示
- レベル名は横文字スタイルで表示（例：Life Skill Lv. / Power Skill Lv.）

**称号システム（2モード切替）:**
- **ビジネスモード**: シンプルで成長志向
  - Lv.1-10：チャレンジャー、ビギナー、スターター
  - Lv.11-30：プログレッサー、アチーバー、パフォーマー
  - Lv.31-70：エキスパート、プロフェッショナル、スペシャリスト
  - Lv.71-100：マスター、エクセレンス、レジェンド
- **ライトモード**: 遊び心のある日本語
  - Lv.1-10：習慣のたね、継続ひよこ、頑張る人
  - Lv.11-30：継続の旅人、習慣育て人、コツコツ戦士
  - Lv.31-70：習慣の達人、継続マスター、習慣王
  - Lv.71-100：習慣レジェンド、継続の神、習慣仙人

**拡張予定:**
- 特殊称号（例：7日連続達成 → 「週間ウォリアー」、1日完璧達成 → 「Perfect Day」）

### 3.15 習慣レビュー機能（新機能）

**基本仕様（MVP段階）:**
- 月1回、システムからレビューリマインドを通知
- ユーザーは任意のタイミングでもレビュー可能
- レビューでは習慣ごとに「続ける／見直す／やめる」を選択可能
- 見直し・やめたい習慣は「休止リスト」に移動し、後で復活可能

**拡張予定:**
- レビュー時に質問形式を導入：
  - 「この習慣は目標に役立った？」
  - 「続けにくかった理由は？」
  - 「次に改善するとしたら？」
- 一言メモの記録機能を追加し、統計画面から振り返り可能に

## 4. 画面構成

### 4.1 主要画面
1. **ダッシュボード** - 今日のスケジュール（時間割/リスト切り替え）+ 全体レベル・称号表示
2. **目標設定** - 長期・短期目標の管理
3. **タスク登録** - 前日夜の習慣選択・設定画面
4. **習慣管理** - 習慣項目・カテゴリの作成・編集・レベル表示
5. **統計・レポート** - 達成率グラフ・分析・進捗表示・習慣レベル詳細
6. **レビュー** - 月次習慣レビュー・休止リスト管理
7. **設定** - 作業時間上限・通知設定・称号モード切替・アカウント管理

### 4.2 レスポンシブ対応
- **PC（1024px以上）**: 3カラムレイアウト
- **タブレット（768px-1023px）**: 2カラムレイアウト
- **スマートフォン（767px以下）**: 1カラムレイアウト
- タッチ操作最適化（スワイプ、ドラッグ&ドロップ）
