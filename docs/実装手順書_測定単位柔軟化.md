# 測定単位柔軟化機能 実装手順書

## 概要
短期目標の測定単位を拡張し、プリセット単位（回数・日数・時間・単語・円・冊）に加えてカスタム単位を追加できるようにする。また、タスク完了時の進捗入力UIを実装する。

## 現状
- 測定単位: `count`（回数）、`days`（日数）、`minutes`（時間）の3種類のみ
- タスク完了時に進捗入力UIなし（自動+1のみ）

## 実装後
- プリセット単位: 6種類（回数・日数・時間・単語・円・冊）
- カスタム単位: ユーザーが自由に追加可能
- タスク完了時: 単位に応じた進捗入力モーダル表示

## Phase 0: データベース変更

### 0.1 カスタム単位テーブル作成
```sql
-- カスタム単位テーブル
CREATE TABLE custom_units (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(user_id, name)
);

-- RLS有効化
ALTER TABLE custom_units ENABLE ROW LEVEL SECURITY;

-- ポリシー作成
CREATE POLICY "Users can manage their own custom units"
  ON custom_units FOR ALL
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
```

### 0.2 短期目標テーブルの測定単位カラム変更
```sql
-- measurement_unit カラムを TEXT に変更（enum から柔軟な文字列へ）
ALTER TABLE short_term_goals
  ALTER COLUMN measurement_unit TYPE TEXT;

-- 新しいプリセット単位のコメント追加
COMMENT ON COLUMN short_term_goals.measurement_unit IS
  'プリセット: count, days, minutes, words, yen, books | カスタム: custom_[unit_name]';
```

### 0.3 進捗履歴テーブル作成（修正機能用）
```sql
-- 進捗入力履歴テーブル
CREATE TABLE progress_entries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  short_term_goal_id UUID NOT NULL REFERENCES short_term_goals(id) ON DELETE CASCADE,
  task_id UUID REFERENCES daily_tasks(id) ON DELETE SET NULL,
  value DECIMAL NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  is_correction BOOLEAN DEFAULT FALSE
);

-- RLS有効化
ALTER TABLE progress_entries ENABLE ROW LEVEL SECURITY;

-- ポリシー作成
CREATE POLICY "Users can manage their own progress entries"
  ON progress_entries FOR ALL
  USING (
    EXISTS (
      SELECT 1 FROM short_term_goals stg
      WHERE stg.id = progress_entries.short_term_goal_id
      AND stg.user_id = auth.uid()
    )
  );

-- 短期目標に現在値カラム追加
ALTER TABLE short_term_goals
  ADD COLUMN current_value DECIMAL DEFAULT 0;
```

### 3.2 時間表示ユーティリティ utils/timeFormatter.ts

```typescript
// 分を時間表示に変換
export function formatMinutesToHoursMinutes(minutes: number): string {
  if (minutes < 60) return `${minutes}分`;
  const hours = Math.floor(minutes / 60);
  const mins = minutes % 60;
  if (mins === 0) return `${hours}時間`;
  return `${hours}時間${mins}分`;
}
```
