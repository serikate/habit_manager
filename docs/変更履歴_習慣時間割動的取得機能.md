## 概要

習慣マスターの時間割設定（schedule）から、タスクの予定時間を動的に取得・表示する機能を追加しました。これにより、既存のタスクにも習慣時間割で設定した時間が自動的に反映されるようになります。

---

## 追加機能

### 1. 習慣時間割からの動的時間取得

**機能**: `getTaskScheduledTime()` 関数を追加

**動作**:
1. タスクに `scheduled_time` が設定されている場合はそれを返す
2. 設定されていない場合は、習慣マスターの `schedule` から該当曜日の時間を取得
3. タスクの日付から曜日を判定し、対応する時間を返す

**ファイル**: `utils/timeCalculator.ts`

```typescript
export function getTaskScheduledTime(task: DailyTask): string | undefined {
  // タスクに scheduled_time が設定されている場合はそれを使う
  if (task.scheduled_time) {
    return task.scheduled_time
  }

  // 習慣タスクでない場合は undefined
  if (!task.habit || !task.habit.schedule) {
    return undefined
  }

  // タスクの日付から曜日を取得
  const taskDate = new Date(task.date)
  const dayOfWeek = taskDate.getDay()

  // 曜日名に変換
  const dayNames = ['sunday', 'monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday']
  const dayName = dayNames[dayOfWeek]

  // 習慣マスターの schedule から該当曜日の時間を取得
  const daySchedule = task.habit.schedule[dayName]
  return daySchedule?.time
}
```

### 3. タスクリストの時間順ソート改善

**変更内容**: `TaskList.tsx` のソート処理を修正

**変更箇所**:
```typescript
// Before
const sortedTasks = allTasks.sort((a, b) => {
  const timeA = 'scheduled_time' in a && a.scheduled_time ? a.scheduled_time : '23:59'
  const timeB = 'scheduled_time' in b && b.scheduled_time ? b.scheduled_time : '23:59'
  return timeA.localeCompare(timeB)
})

// After
const sortedTasks = allTasks.sort((a, b) => {
  let timeA: string | undefined
  let timeB: string | undefined

  if (a.taskType === 'habit') {
    timeA = getTaskScheduledTime(a as DailyTask)  // 🆕 動的取得
  } else if ('scheduled_time' in a) {
    timeA = (a as any).scheduled_time
  }

  if (b.taskType === 'habit') {
    timeB = getTaskScheduledTime(b as DailyTask)  // 🆕 動的取得
  } else if ('scheduled_time' in b) {
    timeB = (b as any).scheduled_time
  }

  const sortTimeA = timeA || '23:59'
  const sortTimeB = timeB || '23:59'

  return sortTimeA.localeCompare(sortTimeB)
})
```

**効果**: 習慣マスターから取得した時間でも正しく時間順にソートされる

### 5. 未完了に戻す機能

**機能**: 完了済みタスクを未完了に戻す

**追加内容**:
- `taskStore.ts` に `uncompleteTask()` 関数を追加
- `TaskList.tsx` に「未完了に戻す」ボタンを追加

**動作**:
1. task_executions テーブルから実行履歴を削除
2. daily_tasks のステータスを `'pending'` に戻す
3. started_at をクリア

**ファイル**: `stores/taskStore.ts`

```typescript
uncompleteTask: async (taskId: string) => {
  // タスクの実行履歴を削除
  await supabase
    .from('task_executions')
    .delete()
    .eq('task_id', taskId)

  // タスクステータスを pending に戻し、started_at をクリア
  await supabase
    .from('daily_tasks')
    .update({
      status: 'pending',
      started_at: null
    })
    .eq('id', taskId)

  // 状態更新
  // ...
}
```

## 使用方法

### 予定時間の表示

1. **習慣マスターで時間を設定**
   - 習慣編集画面で「実行スケジュール設定」を開く
   - 各曜日に時間を設定（例: 月曜 06:00）

2. **ダッシュボードで確認**
   - 既存のタスクでも設定した時間が「予定: 6:00~7:00(60分)」と表示される
   - 新しく生成されるタスクには自動的に時間が設定される

3. **時間順に並ぶ**
   - タスクが自動的に時間順にソートされる
   - 時間未設定のタスクは最後に表示される

### 未完了に戻す

1. **完了済みタスクを確認**
   - ダッシュボードで完了済みタスクを表示

2. **未完了に戻すボタンをクリック**
   - 「未完了に戻す」ボタンをクリック

3. **確認**
   - タスクが未完了（pending）状態に戻る
   - 実行履歴が削除される
   - 「開始」ボタンが表示される

## 技術的な詳細

### データフロー

```
1. 習慣マスター（habits テーブル）
   ↓ schedule: { monday: { enabled: true, time: "06:00" }, ... }

2. タスク生成時
   ↓ generateHabitTaskForDate()
   ↓ daySchedule.time → scheduled_time

3. データベース保存
   ↓ daily_tasks.scheduled_time = "06:00"

4. 表示時（既存タスクの場合）
   ↓ getTaskScheduledTime()
   ↓ task.scheduled_time || habit.schedule[dayName].time

5. 画面表示
   ↓ "予定: 6:00~7:00(60分)"
```

### 後方互換性

- 既存のタスク（scheduled_time が null）でも動作する
- 習慣マスターの schedule から動的に時間を取得
- データベースの変更は不要（scheduled_time は既存カラム）
