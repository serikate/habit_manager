# 習慣タスク×単発タスク 要件定義書

## 1. 概要

### 1.1 文書の目的
本文書は、習慣化×タスク管理アプリにおける「習慣タスク」と「単発タスク」の詳細仕様を定義する。

### 1.2 対象範囲
- 習慣タスクの管理機能（曜日別スケジュール設定）
- 単発タスクの管理機能（カレンダー表示・履歴管理）
- 両タスクの優先度システム
- UI/UX仕様

---

## 2. タスクの種類と基本概念

### 2.1 習慣タスク
**定義**: 継続的な習慣形成を目的とした定期実行タスク

**特徴**:
- 曜日ベースでの自動繰り返し
- 習慣エンティティに紐づく
- レベルアップシステム対象
- 一度設定すれば自動生成

**例**:
- 毎週月・水・金の朝6:00にランニング
- 毎日夜9:00に英語学習
- 火・木・土の夜7:00に筋トレ

### 2.2 単発タスク
**定義**: 一度限りの実行を目的とした独立タスク

**特徴**:
- 習慣に紐づかない独立存在
- 期限重視（deadline必須）
- 完了後は履歴として保管
- レベルシステム対象外

**例**:
- 報告書提出（明日まで）
- 牛乳購入（今日中）
- 車検予約（来月まで）

## 5. 優先度システム

### 5.1 基本ルール
1. **習慣タスク優先**: 基本的に習慣タスクを先に配置
2. **緊急時例外**: 単発タスクが緊急度3（当日中）の場合のみ習慣タスクより優先
3. **同種類内比較**: 優先度（重要度×緊急度）で並び順決定

### 5.2 優先度計算

#### 5.2.1 緊急度計算
```typescript
urgency = {
  3: 当日中（期限当日）
  2: 3日前〜当日前
  1: 4日以上前
}
```

#### 5.2.2 最終優先度
```typescript
priority = importance × urgency  // 1-9の範囲
```

### 5.3 スケジュール配置順序
```
1. 🚨 単発タスク（緊急度3：当日中）
2. 🔄 習慣タスク（全て）
3. ⚡ 単発タスク（緊急度2：3日前〜前日）
4. 📝 単発タスク（緊急度1：4日以上前）
```

#### 6.2.2 履歴操作
- **項目タップ**: 詳細表示
- **スワイプ**: 削除
- **長押し**: 選択モード（複数削除）

## 7. レベルシステムとの関係

### 7.1 習慣タスク
- ✅ **経験値獲得**: 達成率ベースで1-10XP
- ✅ **レベルアップ**: 100XPごとにレベル上昇
- ✅ **称号システム**: 全習慣の平均レベルで称号決定
- ✅ **学習機能**: 平均実行時間を自動更新

### 7.2 単発タスク
- ❌ **経験値なし**: レベルシステム対象外
- ❌ **称号影響なし**: 習慣力とは別扱い
- ✅ **完了記録**: 統計には反映される
- ✅ **達成率**: 個別の達成率は記録

```sql
one_time_tasks (
  id, user_id, title,
  estimated_duration, importance, deadline,
  category, status, created_at
)

-- 統合タスクビュー（両タスク統合表示用）
CREATE VIEW daily_tasks_view AS
  SELECT
    'habit' as task_type,
    habit_id, title, estimated_duration,
    importance, deadline, is_recurring,
    auto_generated, scheduled_time
  FROM habit_tasks
  UNION ALL
  SELECT
    'onetime' as task_type,
    null as habit_id, title, estimated_duration,
    importance, deadline, false as is_recurring,
    false as auto_generated, null as scheduled_time
  FROM one_time_tasks;
```

### 8.2 自動生成ロジック

```typescript
// 習慣タスクの自動生成
function generateHabitTasks(habit: Habit, targetDate: Date) {
  const dayOfWeek = targetDate.getDay(); // 0=Sunday
  const dayName = ['sunday', 'monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday'][dayOfWeek];

  const daySchedule = habit.schedule[dayName];
  if (daySchedule?.enabled) {
    return {
      habit_id: habit.id,
      date: formatDate(targetDate),
      estimated_duration: habit.default_duration,
      scheduled_time: daySchedule.time,
      is_recurring: true,
      auto_generated: true
    };
  }
  return null;
}
```
