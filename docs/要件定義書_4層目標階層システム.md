# 4層目標階層システム 要件定義書

## 1. 概要

### 1.1 目的
長期的な目標達成を支援するため、「1年後ビジョン」「長期目標」「短期目標」「習慣」の4層階層構造で目標を管理し、日々の習慣実行を通じて着実に目標達成へ導くシステム。

### 1.2 背景
従来の3層構造（長期目標→短期目標→習慣）では、より長期的なビジョンとの紐づけが不明確だった。1年後ビジョンを追加することで、日々の習慣が最終的なビジョン達成にどう貢献しているかを可視化する。

---

## 2. 階層構造

### 2.1 4層構造の全体像

```
1年後ビジョン（Vision）
  │
  └─ 長期目標（Long-term Goal）
       │
       └─ 短期目標（Short-term Goal）
            │
            └─ 習慣（Habit）
```

### 2.2 階層関係の制約

| 関係 | 制約 | 説明 |
|------|------|------|
| 習慣 → 短期目標 | **必須**・1対1 | すべての習慣は必ず1つの短期目標に紐づく |
| 短期目標 → 長期目標 | **必須**・1対1 | すべての短期目標は必ず1つの長期目標に紐づく |
| 長期目標 → 1年後ビジョン | **必須**・1対1 | すべての長期目標は必ず1つのビジョンに紐づく |

**重要**: 階層の途中をスキップすることは不可。習慣を作成するには、まずビジョン→長期目標→短期目標の順で作成する必要がある。

---

## 3. 各層の詳細仕様

### 3.1 1年後ビジョン（Vision）

#### 3.1.1 定義
1年後に達成したい大きな目標やなりたい姿を表す最上位の目標。

#### 3.1.2 作成項目

| 項目 | 必須 | 説明 |
|------|------|------|
| タイトル | ○ | ビジョンの名称（例: 「英語でビジネス会話ができるようになる」） |
| 説明 | | 詳細な説明やモチベーション |
| 期間 | ○ | 6ヶ月〜1年半の範囲で設定（月単位） |

#### 3.1.3 期間設定

- **最小期間**: 6ヶ月
- **最大期間**: 18ヶ月（1年半）
- **設定単位**: 1ヶ月刻み
- **期限計算**: 作成日 + 設定期間

#### 3.1.4 制約

- 複数のビジョンを同時に設定可能（上限なし）
- ビジョンには最低1つの長期目標が必要
- 達成後も継続して表示可能

#### 3.1.5 進捗計算

```
ビジョン期間（月数）= N
紐づく長期目標数 = M

各長期目標の進捗に基づいて計算:
ビジョン進捗率 = Σ(長期目標の進捗率 × 長期目標の重み) / M
```

※長期目標の重みは均等（各 1/M）

---

### 3.2 長期目標（Long-term Goal）

#### 3.2.1 定義
1年後ビジョンを達成するために、半年後に達成すべき中期的な目標。

#### 3.2.2 作成項目

| 項目 | 必須 | 説明 |
|------|------|------|
| タイトル | ○ | 長期目標の名称（例: 「TOEIC 800点達成」） |
| 説明 | | 詳細な説明 |
| 1年後ビジョン | ○ | 紐づけるビジョンを選択 |
| 期間パターン | ○ | 2パターンから選択 |

#### 3.2.3 期間設定

紐づくビジョンの期間の半分を基準とし、以下の2パターンから選択:

**パターン1: 正確に半分**
- ビジョン期間12ヶ月 → 長期目標期間6ヶ月
- ビジョン期間8ヶ月 → 長期目標期間4ヶ月

**パターン2: 半分の月の月末まで**
- ビジョン期間12ヶ月（3月開始）→ 9月末まで（6.x ヶ月）
- より自然な区切りで管理したい場合に使用

#### 3.2.4 制約

- 1つのビジョンに複数の長期目標を紐づけ可能
- 長期目標には最低1つの短期目標が必要
- 各月に最低1つの短期目標が存在する必要がある

#### 3.2.5 進捗計算

```
長期目標期間（月数）= N
各月の短期目標数 = Mn（月によって異なる可能性あり）

1つの短期目標達成で加算される進捗 = 100% ÷ N ÷ その月の短期目標数

例: 6ヶ月の長期目標
- 1月目: 短期目標2個 → 各達成で 100% ÷ 6 ÷ 2 = 8.33%
- 2月目: 短期目標3個 → 各達成で 100% ÷ 6 ÷ 3 = 5.56%
- 3月目: 短期目標1個 → 達成で 100% ÷ 6 ÷ 1 = 16.67%
```

**進捗の再計算**:
- 短期目標の追加・削除時は全ての進捗を再計算
- 過去に達成した短期目標の貢献度も再計算される

---

### 3.3 短期目標（Short-term Goal）

#### 3.3.1 定義
長期目標を達成するために、1ヶ月後に達成すべき定量的に測定可能な目標。

#### 3.3.2 作成項目

| 項目 | 必須 | 説明 |
|------|------|------|
| タイトル | ○ | 短期目標の名称（例: 「単語を500語覚える」） |
| 長期目標 | ○ | 紐づける長期目標を選択 |
| 目標値 | ○ | 達成基準となる数値（小数点可） |
| 測定単位 | ○ | プリセット6種 or カスタム単位 |
| 期限 | | 任意で細かい期限を設定 |
| 達成後表示 | | 達成後に継続表示するか |

#### 3.3.3 期間設定

- **固定1ヶ月**: すべての短期目標は1ヶ月間
- **月の判定**: 作成日が属する月
- **期限計算**: 作成月の月末

#### 3.3.4 測定単位

**プリセット単位（6種類）:**

| 単位 | キー | 入力方法 | 接尾辞 |
|------|------|----------|--------|
| 回数 | count | 自動+1 | 回 |
| 日数 | days | 自動+1（1日1回） | 日 |
| 時間（分） | minutes | 実行時間から自動 | 分 |
| 単語 | words | 手動入力 | 語 |
| 円 | yen | 手動入力 | 円 |
| 冊 | books | 手動入力 | 冊 |

**カスタム単位:**
- ユーザーが自由に追加可能（例: ページ、km、kg）
- カスタム単位は全て手動入力
- ユーザーごとに保存

#### 3.3.5 制約

- 各月に最低1つの短期目標が必須（0個は不可）
- 1つの長期目標に複数の短期目標を紐づけ可能
- 短期目標には最低1つの習慣が必要

#### 3.3.6 進捗計算

```
進捗率 = (現在値 / 目標値) × 100%
```

- 100%超過も表示可能（例: 120%）
- 進捗は累積方式
- 100%以上で自動的に「達成」状態

---

### 3.4 習慣（Habit）

#### 3.4.1 定義
短期目標を達成するための具体的な日々の行動。

#### 3.4.2 作成項目

| 項目 | 必須 | 説明 |
|------|------|------|
| 習慣名 | ○ | 習慣の名称（例: 「英単語学習」） |
| 短期目標 | ○ | 紐づける短期目標を選択 |
| カテゴリ | | 分類用カテゴリ |
| デフォルト所要時間 | ○ | 想定実行時間（分） |
| 繰り返し設定 | ○ | 毎日 / 週○回 / 特定曜日 |

#### 3.4.3 制約

- すべての習慣は必ず短期目標に紐づく
- 目標なしの習慣は作成不可
- 1つの習慣は1つの短期目標にのみ紐づく

#### 3.4.4 タスク完了時の進捗記録

習慣タスク完了時に、紐づく短期目標に進捗が加算される:

| 測定単位 | 完了時の動作 |
|----------|-------------|
| 回数 | 自動で +1 |
| 日数 | 自動で +1（同日複数回でも1回のみ） |
| 時間（分） | 実行時間を自動計算（編集可） |
| その他 | 手動で数値を入力 |

---

## 4. 進捗計算の詳細

### 4.1 計算フローチャート

```
習慣タスク完了
    ↓
短期目標の current_value を更新
    ↓
短期目標の進捗率を計算 (current_value / target_value × 100%)
    ↓
短期目標が100%達成の場合、is_achieved = true
    ↓
長期目標の進捗率を再計算
    ↓
1年後ビジョンの進捗率を再計算
```

### 4.2 長期目標の進捗計算（詳細）

```javascript
function calculateLongTermGoalProgress(longTermGoalId) {
  const goal = getLongTermGoal(longTermGoalId)
  const periodMonths = goal.period_months  // N

  // 月ごとの短期目標を取得
  const shortTermGoalsByMonth = groupByMonth(goal.shortTermGoals)

  let totalProgress = 0

  for (const [month, goals] of shortTermGoalsByMonth) {
    const monthGoalCount = goals.length  // Mn
    const achievedCount = goals.filter(g => g.is_achieved).length

    // この月の貢献度 = 達成数 × (100 / N / Mn)
    const monthContribution = achievedCount * (100 / periodMonths / monthGoalCount)
    totalProgress += monthContribution
  }

  return totalProgress
}
```

### 4.3 再計算トリガー

以下の操作時に進捗を再計算:

1. **短期目標の追加**: 該当月の全短期目標の貢献度が変化
2. **短期目標の削除**: 該当月の全短期目標の貢献度が変化
3. **短期目標の達成/未達成切り替え**: 長期目標・ビジョンの進捗更新
4. **習慣タスクの完了**: 短期目標→長期目標→ビジョンの順に更新

## 5. 削除時の挙動

### 5.1 1年後ビジョンの削除

1. 確認ダイアログを表示
2. 削除実行時:
   - ビジョン自体は削除
   - 紐づく長期目標は削除
   - 紐づく短期目標は削除
   - **習慣は削除されない**（紐づけのみ解除）
3. 習慣は「未紐づけ」状態になり、再紐づけ可能

### 5.2 長期目標の削除

1. 確認ダイアログを表示
2. 削除実行時:
   - 長期目標自体は削除
   - 紐づく短期目標は削除
   - **習慣は削除されない**（紐づけのみ解除）
3. 習慣は「未紐づけ」状態になり、再紐づけ可能

### 5.3 短期目標の削除

1. 確認ダイアログを表示
2. 削除実行時:
   - 短期目標自体は削除
   - **習慣は削除されない**（紐づけのみ解除）
3. 習慣は「未紐づけ」状態になり、再紐づけ可能
4. **注意**: 該当月の短期目標が0個になる場合は警告を表示

## 7. 進捗計算用ストアドプロシージャ

```sql
-- 長期目標の進捗を計算
CREATE OR REPLACE FUNCTION calculate_long_term_goal_progress(p_long_term_goal_id UUID)
RETURNS NUMERIC AS $$
DECLARE
  v_period_months INTEGER;
  v_total_progress NUMERIC := 0;
  v_month RECORD;
BEGIN
  -- 長期目標の期間を取得
  SELECT period_months INTO v_period_months
  FROM long_term_goals
  WHERE id = p_long_term_goal_id;

  -- 月ごとに計算
  FOR v_month IN
    SELECT
      target_month,
      COUNT(*) as goal_count,
      SUM(CASE WHEN is_achieved THEN 1 ELSE 0 END) as achieved_count
    FROM short_term_goals
    WHERE long_term_goal_id = p_long_term_goal_id
    GROUP BY target_month
  LOOP
    -- この月の貢献度 = 達成数 × (100 / 期間月数 / この月の目標数)
    v_total_progress := v_total_progress +
      (v_month.achieved_count * (100.0 / v_period_months / v_month.goal_count));
  END LOOP;

  RETURN COALESCE(v_total_progress, 0);
END;
$$ LANGUAGE plpgsql;

-- 1年後ビジョンの進捗を計算
CREATE OR REPLACE FUNCTION calculate_vision_progress(p_vision_id UUID)
RETURNS NUMERIC AS $$
DECLARE
  v_total_progress NUMERIC := 0;
  v_goal_count INTEGER := 0;
  v_goal RECORD;
BEGIN
  FOR v_goal IN
    SELECT id FROM long_term_goals WHERE vision_id = p_vision_id
  LOOP
    v_total_progress := v_total_progress + calculate_long_term_goal_progress(v_goal.id);
    v_goal_count := v_goal_count + 1;
  END LOOP;

  IF v_goal_count = 0 THEN
    RETURN 0;
  END IF;

  RETURN v_total_progress / v_goal_count;
END;
$$ LANGUAGE plpgsql;
```

## 9. バリデーションルール

### 9.1 1年後ビジョン作成時

- タイトル: 1文字以上、100文字以下
- 期間: 6〜18ヶ月の範囲内

### 9.2 長期目標作成時

- タイトル: 1文字以上、100文字以下
- 1年後ビジョン: 必須選択
- 期間パターン: 2択から選択必須

### 9.3 短期目標作成時

- タイトル: 1文字以上、100文字以下
- 長期目標: 必須選択
- 目標値: 0より大きい数値
- 測定単位: 必須選択

### 9.4 短期目標削除時

- 削除後にその月の短期目標が0個になる場合は警告
- 確認後のみ削除可能

### 9.5 習慣作成時

- 習慣名: 1文字以上、50文字以下
- 短期目標: 必須選択
- デフォルト所要時間: 5分以上、480分以下

## 10. 移行計画

### 10.1 既存データの移行

既存の3層構造からの移行手順:

1. デフォルトビジョン「マイビジョン（12ヶ月）」を自動作成
2. 既存の長期目標をデフォルトビジョンに紐づけ
3. `vision_id` に NOT NULL 制約を追加

### 10.2 移行SQL

```sql
-- 1. デフォルトビジョンを作成
INSERT INTO visions (user_id, title, period_months, deadline)
SELECT DISTINCT
  user_id,
  '自動作成されたビジョン',
  12,
  NOW() + INTERVAL '12 months'
FROM long_term_goals;

-- 2. 既存の長期目標を紐づけ
UPDATE long_term_goals ltg
SET vision_id = (
  SELECT v.id FROM visions v
  WHERE v.user_id = ltg.user_id
  LIMIT 1
```
